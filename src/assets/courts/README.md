# Court illustrations

Public-domain Vector Playing Cards by Byron Knoll, sourced from:
https://github.com/adamlacoste/vector-playing-cards
Original project: https://code.google.com/archive/p/vector-playing-cards/

These are the twelve `jack`, `queen`, and `king` `_of_<suit>2.svg` files.
The SVG viewport is cropped to the central illustration; editor metadata and
whitespace were removed. Corner indices are rendered separately by the game.

Path coordinates are rounded to two decimal places to reduce file size.
