## Work completed

- Implemented `src/ui/dialogs.js`:
  - `renderDialogs(rootElement, state, app)`: creates and manages `#modal-container` for modal presentation.
  - Menu dialog (`#menu-dialog`, `role="dialog"`, `aria-modal="true"`, `aria-labelledby="dialog-title-menu"`):
    - Actions: "Nowa gra" (`#btn-menu-new-game`), "Rozdaj ponownie" (`#btn-menu-restart`), "Wstrzymaj grę" (`#btn-menu-pause`), "Zasady i pomoc" (`#btn-menu-help`), "Wróć do gry" (`#btn-menu-resume`), and close button (`#btn-dialog-close`).
    - Tryb dobierania kart: toggle selector between "Dobieraj 1" (`#btn-mode-draw-1`) and "Dobieraj 3" (`#btn-mode-draw-3`) with `role="radiogroup"` and `aria-checked`.
  - Pause overlay (`#pause-dialog`, `role="dialog"`, `aria-modal="true"`, `aria-labelledby="dialog-title-pause"`):
    - Displays elapsed game time (`#pause-dialog .pause-stat` with formatted mm:ss) and move count.
    - Actions: "Wznów grę" (`#btn-resume-game`) and "Menu gry" (`#btn-pause-menu`).
    - Board concealment (F07): adds `.is-concealed` class to `#board-area`, obscuring cards with blur filter and dark overlay so card faces cannot be inspected while paused.
  - Replacement confirmation dialog (`#confirm-dialog`, `role="dialog"`, `aria-modal="true"`, `aria-labelledby="dialog-title-confirm"`):
    - Protects active unwon games (F05): prompts confirmation only when `state.started && !state.isWon`. Unstarted or won games replace immediately without prompt.
    - Specific titles and messages for New Game ("Rozpocząć nową grę?"), Restart ("Rozdać ponownie?"), and Draw mode changes ("Zmienić tryb na dobieranie po 1/3?").
    - "Anuluj" (`#btn-confirm-cancel`): cancels dialog, strictly preserving board state, undo/redo history, and resuming clock.
    - "Rozpocznij" / "Rozdaj ponownie" / "Zmień i rozpocznij" (`#btn-confirm-accept`): performs the requested operation.
  - Help dialog (`#help-dialog`, `role="dialog"`, `aria-modal="true"`, `aria-labelledby="dialog-title-help"`):
    - Comprehensive Polish explanations (N02): Cel gry (objective), Kolumny robocze (tableau builds), Sekwencje (moving sequences), Stos i skrawek (draw & waste recycling), Sterowanie dotykiem i myszą (touch/mouse controls), Sterowanie klawiaturą (keyboard navigation & shortcuts).
  - Dialog focus management & accessibility (N01 / T18):
    - Focus trapping: Tab and Shift+Tab loop within the active dialog, preventing focus escape to background elements.
    - Focus restoration: remembers the trigger element before opening (e.g. `#btn-menu`) and restores focus upon closing.
    - Initial focus: auto-focuses first interactive element in dialog.
    - Escape key: closes active dialog or resumes game if paused.
    - Backdrop dismissal: clicking outside card on modal overlay closes non-destructive dialogs (menu, help).
