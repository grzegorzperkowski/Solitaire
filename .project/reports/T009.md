## Work completed

- Implemented `src/ui/layout.js`:
  - `calculateBoardDimensions`: computes exact pixel geometry for any container width; chooses gap (3px for <=360px, 4px for >360px, up to 10px on desktop), side padding (min 8px), and bounds `cardWidth` between 38px and 104px (capped on desktop with centered board).
  - Maintains strict 5:7 aspect ratio (`cardHeight = 1.4 * cardWidth`).
  - Computes vertical overlaps: face-up overlap `max(24, 0.28 * cardHeight)` (>=24px band per U03), hidden overlap (12px).
  - Computes Draw 3 waste fan offset (`fanOffset`) fitting inside the 2-column waste area without covering foundation slot 3.
  - `calculateColumnHeight`: computes vertical pixel span for any column with $d$ hidden and $u$ visible cards.
  - `setupResponsiveLayout`: attaches `ResizeObserver` (with window resize fallback) that updates CSS variables and triggers re-render only when container width changes, avoiding unwanted loops on vertical content growth.
- Implemented `src/ui/cards.js`:
  - Distinct SVG suit paths for trefl (♣), karo (♦), kier (♥), and pik (♠).
  - `getCardDetails`: maps all 52 card IDs to Polish names, ranks (1..13), suits, and colors.
  - `createCardElement`: generates stable card DOM elements. Face-up cards render compact horizontal corner rank+suit indices inside the 24px exposed band with computed font size >=14px (U03), plus central suit artwork / court motifs (A, J, Q, K).
  - Strict compliance with N02: face-down cards render an intricate geometric SVG back pattern, with card ID, rank, and suit completely absent from DOM text, attributes, and SVG markup (`aria-label="Karta zakryta"`).
  - `createEmptySlotElement`: renders accessible empty placeholders for stock (with recycle indicator when applicable), waste, 4 foundations (with faint suit watermarks), and 7 tableau columns (with 'K' watermark).
- Implemented `src/ui/render.js`:
  - `createBoardStructure`: constructs semantic board DOM with header (timer, title, move count), status banner, top row (7 slots: stock, 2-column waste, 4 foundations), tableau vertical scroller with 7 columns, 44px scroll handle and accessible scroll buttons for long overflowing columns, and bottom controls bar.
  - `renderGame`: synchronizes DOM from `app.getState()`. Handles stock count badge, Draw 1 vs Draw 3 fanned waste cards, foundation tops, vertically cascaded tableau cards, and active/disabled states on Undo/Redo buttons.
- Updated `src/styles.css` & `index.html`:
  - Mobile-first portrait styling supporting 320–430px screens with zero horizontal overflow (`scrollWidth <= clientWidth + 1px`).
  - Viewport safe areas respected via `max(8px, env(safe-area-inset-*))`.
  - Primary bottom controls ("Cofnij", "Ponów", "Podpowiedź", "Menu") meet minimum 44×44 CSS px touch targets (U06).
  - Preserved semantic `<main id="game-app"><h1 id="page-title">Pasjans Klondike</h1>...</main>` for bootstrap test compliance.
- Updated `src/main.js`:
  - Connects renderer to `createApp()` instance and subscribes to state and responsive layout changes.
- Added test suites:
  - Unit tests (`tests/unit/layout.test.js`): 6 tests covering 320px narrow layout, 360/375/390/430px viewports, 1440px desktop cap, long column height calculations, 52-card mapping, and face-down card concealment.
  - E2E Playwright tests (`tests/e2e/layout.spec.js`): 12 tests verifying 8 viewports (320x568, 360x640, 375x667, 390x844, 430x932, 1440x900, 568x320 landscape, 844x390 landscape), no horizontal scroll, typography (>=14px ranks, >=24px bands), waste fan containment without foundation overlap, face-down card concealment, long column (19 cards) reachability, and scroll controls.
  - Captured screenshots for visual verification at 320, 375, 390, and 1440 px in `test-results/screenshots/`.
