## Work completed

- `npm run test:simulation -- --profile=ci|release` parses the profile and runs `tests/unit/simulation.test.js` with `SOLITAIRE_SIMULATION_PROFILE`. An unknown or missing profile exits nonzero and does not start Vitest.
- CI plays seeds 0–999 in Draw 1 and Draw 3, plus seed 4294967295 in both modes (2002 deals), at most 300 steps. Release selects seeds 0–9999 in both modes, plus the same maximum seed, at most 1,000 steps. The release profile was not executed.
- Each step uses a SplitMix32 selector (increment `0x9E3779B9`), not the engine Mulberry32 shuffle. The selector seed is `(seed + drawCount * 0x6C62272E) >>> 0`. About one step in five is an intentionally rejected command. The other steps prefer, by `(seed + drawCount) % 3`, a reveal or foundation build, draw/recycle, or a foundation return, and otherwise take any legal move.
- After every accepted action the run checks `assertInvariants`, that 51 foundation cards is not a win, that `validateMove` and `applyMove` agree, that every enumerated command validates exactly once, and that the input board’s JSON is unchanged. A rejected command must fail both calls with the same reason and leave the board unchanged. Play stops at a win, at no legal move, or at the step bound. Repeated positions keep playing, so recycling cannot hang the run.
- A failure throws `simulation failed:` plus JSON with `seed`, `drawCount`, `rulesVersion`, `shuffleVersion`, `selectorSeed`, `step`, `actionHistory` and `assertion`.
- The passing CI run reached three won boards. That is a count for this selector, not a solvability or win-rate claim. No history, Undo, Redo, statistics or save/restore was exercised.
