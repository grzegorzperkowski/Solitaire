## Work completed

- `validateMove` and `applyMove` share one pure evaluation. Success returns a new frozen board. Failure returns `{ok:false, reason}` and does not change the frozen input.
- Tableau moves take the face-up suffix that starts at `cardIndex`. The suffix must descend by one rank in alternating colors. An empty column accepts only a king or a king-headed suffix. Removing the last face-up card reveals exactly one hidden card in that same result (`revealed` is that id, or null).
- Foundations keep suit order trefl, karo, kier, pik. They accept only the next same-suit rank, one exposed card at a time. The top foundation card can return to a legal tableau. Foundation-to-foundation moves reject.
- Only the waste top moves, and only to tableau or foundation. Stock and waste are not destinations. Buried waste cannot be named.
- Stable reasons: `invalid-command`, `unsupported-command`, `invalid-state`, `illegal-source`, `illegal-sequence`, `illegal-destination`. `draw` and `recycle` return `unsupported-command`.
- `assertInvariants` throws `invalid-state` for a broken deck, face-up order or foundation contents. `isWon` is true only when each foundation is exactly ranks 1–13 of its suit and stock, waste and tableau are empty. 51 foundation cards is not a win.
- Full-deck fixtures are built in `tests/fixtures/boards.js`. The broken face-up run and illegal foundations are used only at validation boundaries. Golden deals for seeds 0, 1, 42 and 4294967295 still pass `cards.test.js` and `assertInvariants`.
- P2 transfer subset is implemented. Draw, recycle, legal-move enumeration and the hint half of T08 are not. A board that is not won has no loss flag.
