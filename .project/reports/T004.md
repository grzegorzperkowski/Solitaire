## Work completed

- `{ type: 'draw' }` and `{ type: 'recycle' }` are real commands. Success returns a new frozen board and `revealed: null`. Failure returns `{ ok: false, reason }` and leaves the frozen input in place. Tableau, waste and foundation transfers are unchanged.
- Stock and waste stay bottom at index 0 and top at the last index. Draw pops the stock top onto the waste, once per card, at most `drawCount` times (1 or 3). Fewer remaining stock cards move as a shorter batch. Cards already in the waste stay below the new ones. Only the new waste top is playable.
- Hand example, stock bottom→top `[D,C,B,A]` = ids `[16,51,38,1]`. Draw 3 produces waste `[1,38,51]` (`[A,B,C]`), stock `[16]`, and exposes `51`. Recycle of waste `[A,B,C]` produces stock `[C,B,A]` = `[51,38,1]` and an empty waste. It does not also draw. The next draw starts at `A` (`1`).
- If the exposed top was played, recycle uses only the cards still in the waste. Playing `C` leaves waste `[A,B]` and stock `[B,A]`. Playing `C` and `B` leaves stock `[A]`. A full unplayed Draw 3 cycle of stock `[0,1,2,3,4]` returns that same array. A second cycle does too. One foundation play of the dealt ace leaves stock `[1,2,3,4]`, and the next Draw 3 is waste `[4,3,2]` with stock `[1]`. Two foundation plays leave stock `[2,3,4]`, and the next draw starts at `4`.
- Empty stock rejects `draw`. Empty waste rejects `recycle`. Both empty rejects both. Recycle while the stock still has cards rejects. None of those change the board. A command with any field besides `type` is `invalid-command`. `drawCount` other than 1 or 3 is `invalid-state`. The reason for a well-formed draw/recycle whose pile precondition fails is `illegal-source`. `unsupported-command` is no longer returned.
- `getLegalMoves(state)` returns a fresh command array. An unreadable board returns `[]`. The scan order is not the hint ranking (that stays in T014): `draw` if legal, else `recycle` if legal, then tableau columns 0..6, each face-up `cardIndex` from `faceUpStart` through the top, then the waste pile, then foundation indexes 0..3. Each source tries tableau destinations 0..6 before foundation destinations 0..3. Only commands `validateMove` accepts are included, so buried waste cards and hidden tableau cards are absent. Foundation returns are included. The same command is not repeated.
- `isWon` is unchanged. Fifty-one foundation cards is not a win. A blocked face-up board with empty stock and waste has an empty legal list and no loss flag. A legal draw or recycle keeps that list nonempty.
