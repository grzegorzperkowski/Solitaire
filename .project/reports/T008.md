## Work completed

- Implemented `src/app.js`:
  - `createApp`: manages session instance, preferences, persistence metadata, active time, pause state, active dialogs, writer ownership, and subscriptions.
  - Active clock accumulation using `performance.now()`: does not count before first legal action; excludes paused time, open modal dialogs, and hidden document state (`document.hidden`). Undo/Redo does not rewind elapsed time.
  - Automatic persistence: periodic 5-second checkpoint, `pagehide` and `visibilitychange` (hidden) handler with force-settle of pending active time before save.
  - Safe restoration: restores saved session upon initialization; starts paused if the game was already in progress (F07 / T13).
  - Single-writer tab ownership (F13 / T14): requests Web Lock `pl.solitaire.writer` with `{ ifAvailable: true }`. If held, tab enters read-only mode with Polish advisory message.
  - Storage event and revision fallback: monitors `storage` events and checks revision before write; detects cross-tab conflicts and drops writer ownership safely.
  - Clean lifecycle: `destroy()` releases Web Lock, clears intervals and detaches listeners.
- Updated `src/main.js`:
  - Instantiates `createApp()`, exposes `window.__SOLITAIRE_APP__` for testing and debugging, and initializes controller.
- Set up Playwright infrastructure:
  - Added `@playwright/test` devDependency in `package.json` with script `"test:e2e": "playwright test"`.
  - Configured `playwright.config.js` with Vite preview server on port 5173 and Chromium desktop/mobile emulation readiness.
  - Updated `.github/workflows/ci.yml` with Playwright installation and E2E test step.
  - Updated `.gitignore` with `/test-results/` and `/playwright-report/`.
- Unit test suite (`tests/unit/app.test.js`):
  - 7 comprehensive tests covering active clock measurement, pause/dialog/visibility exclusion, reload starting paused, 5s checkpoint & pagehide saving, Web Lock exclusive writer grant / conflict denial, fallback revision conflict detection, and session lifecycle operations.
- E2E browser test suite (`tests/e2e/storage.spec.js`):
  - 2 Playwright Chromium tests validating real persistence across reload starting paused (F07 / T13) and multi-tab single-writer exclusivity via Web Locks (F13 / T14).
