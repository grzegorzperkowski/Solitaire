## Work completed

- Implemented Pointer Events drag & drop architecture in `src/ui/input.js` (ARCHITECTURE §9, REQUIREMENTS F02, U08, U09):
  - Primary pointer tracking: tracks primary pointer ID, start coordinates, current position, grab offset, and source pile info. Ignores secondary pointers.
  - Touch interaction lifecycle (F02 / ARCHITECTURE §9):
    - Unselected touch movements preserve native browser panning/scrolling (`pan-y pinch-zoom`).
    - Tapping a card selects it (F01).
    - Selected movable cards/sequences have `touch-action: pinch-zoom` and single-finger movement drags the selected sequence.
  - Mouse interaction lifecycle:
    - Mouse can immediately drag unselected legal cards or sequences; upon dragging, the card is selected and legal targets are highlighted.
  - Movement threshold:
    - 6 CSS px threshold distinguishes taps from drags (`Math.hypot(dx, dy) >= 6`).
    - Sub-threshold gestures cleanly execute as normal taps without creating overlays.
  - Draggable sources:
    - Tableau exposed cards and valid multi-card sequences (from grabbed card index down to column bottom).
    - Playable waste top card.
    - Foundation top cards (can be dragged back to tableau if legal).
    - Stock is excluded from dragging (only tap draw/recycle).
  - Pointer capture & Drag Overlay (`#drag-overlay`):
    - Sets pointer capture on source element during active drag (`setPointerCapture`).
    - Creates a GPU-composited fixed overlay element with `translate3d(x, y, 0)`, preserving precise grabbed card offset with zero jump.
    - Clones all dragged sequence cards with exact layout widths, heights, and vertical overlap.
    - Dimmed opacity (`.is-dragging-source`) on source card nodes in the tableau/waste.
    - Respects `prefers-reduced-motion` (omits scale/shadow filters when reduced motion is preferred).
  - Hit testing & drop target feedback:
    - Real-time hit-testing against 7 tableau columns and 4 foundations.
    - Highlighted drop target (`.is-drop-hover`) when hovering over legal destination targets.
    - Synchronous hit-testing on pointerup to guarantee exact release coordinates.
  - Edge autoscroll:
    - Detects pointer within 32px of `#tableau-scroller` top or bottom edges.
    - Smoothly scrolls container vertically with speed proportional to edge proximity, capped at 240 px/s (ARCHITECTURE §9).
  - Cancellation & gesture safety:
    - Escape key cancels active drag immediately.
    - `pointercancel`, `lostpointercapture`, window blur, resize, orientation change, or outside release clean up overlay, restore cards, and leave game state untouched (0 commands executed).
    - Invalid drop triggers rejection shake feedback (`.shake-animation`) on target pile and announces rejection in Polish.
  - Follow-up click suppression:
    - Single-click suppression (`suppressNextClick`) stops the browser's synthetic click following a committed or cancelled drag.
    - Never blocks intentional clicks on bottom control buttons (Cofnij, Ponów, Menu, Podpowiedź).
- Mobile cancellation regression: pointer cancellation and lost-capture events only cancel the active drag when their `pointerId` matches it. Previously, an unrelated pointer's cancellation could abort the card being dragged.
- Review feedback: root overscroll is disabled for Android Chrome; a non-passive touchmove guard prevents downward overscroll at the page top on iOS Safari while allowing scrollable ancestors to scroll and leaving multi-touch pinch gestures alone.
- Updated `src/styles.css`:
  - Added `.card-node { touch-action: pan-y pinch-zoom; user-select: none; -webkit-user-drag: none; }`.
  - Added `.card-node.is-selected { touch-action: pinch-zoom; }`.
  - Added `.card-node.is-dragging-source { opacity: 0.25; }`.
  - Added `.drag-overlay` with fixed coordinates, high z-index (2000), GPU translation, and drop shadow.
  - Added `@media (prefers-reduced-motion: reduce)` rule for drag overlay.
  - Added `.is-drop-hover` styling for tableau and foundation drop zones (cyan outline and glow).
- Created automated test suite in `tests/e2e/input.spec.js` (11 tests):
  - Mouse drag moves single card to legal foundation (seed 42).
  - Mouse drag moves multi-card sequence across tableau columns (seed 9).
  - Invalid mouse drop leaves board and move count unchanged.
  - Outside mouse drop leaves board and move count unchanged.
  - Escape key cancels active drag gesture without changing state.
  - `pointercancel` event cancels drag safely.
  - Movement below 6px threshold acts as tap selection without dragging.
  - Touch lifecycle: unselected touch does not drag; selected touch drags.
  - Undo after drag restores exact board and move count.
  - Rapid tap after drag does not trigger duplicate command.
  - Drag and drop verified at 320px (`narrow-portrait-320`) and 390px (`iphone-standard-390`) viewports.
