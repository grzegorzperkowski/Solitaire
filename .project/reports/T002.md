## Work completed

- `createGame({ seed, drawCount, rulesVersion=1, shuffleVersion=1 })` returns a frozen GameState. Card id 0–51 maps to suit index `floor(id / 13)` (trefl, karo, kier, pik), rank `id % 13 + 1`, and color red for karo/kier and black for trefl/pik. Color is not stored on the state.
- Shuffle version 1 is Mulberry32 with the state starting at the seed, including 0, then Fisher–Yates from index 51 down to 1. The deal pops the shuffled array from the end: for row 0..6, one card goes to columns row..6. Only the last card of each column is face up (`faceUpStart = length - 1`). The remaining 24-card prefix is the stock. Waste and four foundations start empty.
- Invalid options throw `Error` with `reason`: `invalid-options`, `invalid-seed`, `invalid-draw-count`, `unsupported-rules-version`, `unsupported-shuffle-version`. Omitted rule/shuffle versions default to 1. `drawCount` must be 1 or 3. The seed must be an integer 0..4294967295. A rejected call does not return a board.
- Golden arrays for seeds 0, 1, 42 and 4294967295 live in `tests/fixtures/deals.json`. They were produced before the engine implementation by a separate Python Mulberry32/Fisher–Yates program and checked against a separate Node program. Both shuffles matched. The first seed-0 sample was also checked by hand through the XOR step: state `1831565813`, unsigned `>>> 15` = `55894`, xor = `1831576483`, and the sample `0.26642920868471265` matched both programs. An unshuffled deal trace matches the spec: stock `0..23`, column 0 is `[51]`, column 1 is `[50, 44]`, column 6 has length 7 and ends at 24. The unit test reapplies that row-wise pop to every golden shuffled array. `cards.js` output was not copied into the fixture.
- CI workflow installs the lockfile, runs the unit suite and builds on Node 22. `package.json` and `vite.config.js` already ran non-watch Vitest and the production build, so they were not changed. No runtime dependency was added. `test:simulation` stays for its later task.
- P1 exit for this task: the four seeds match the fixture, each deal has 28 tableau cards, 24 stock and 7 face-up cards, invalid seeds/modes/versions reject, and a clean install plus production build passed. No game UI.
