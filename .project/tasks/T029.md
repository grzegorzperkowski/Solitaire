## Scope

Implement four distinct, original, native-browser victory effects: classic bouncing card cascade with trails, kings moving into a fan, suit-symbol fireworks, and a card tornado that spirals then scatters. Select effects from a persisted validated shuffle bag with no repeats before a cycle completes and no repeat at cycle boundaries.
