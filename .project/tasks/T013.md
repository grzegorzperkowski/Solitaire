# T013 — Physical-device touch feasibility gate

- Milestone: P6
- Dependencies: T012
- Model suitability (advisory, not assignment): Any model with physical-device access; human-assisted execution is allowed.
- Status: see [TASKS.md](../TASKS.md); only the coordinator assigns this task.

## Scope

Execute the P6 Android/iPhone gesture script and fix only defects necessary to pass this gate, adding regressions. Do not start hints/art polish. If devices are unavailable, record BLOCKED and the exact missing evidence.

## Required inputs

Read [AGENTS.md](../../AGENTS.md), [STATUS.md](../STATUS.md), [HANDOFF.md](../HANDOFF.md) and any existing task report first. Then read: IMPLEMENTATION_PLAN P6; TEST_PLAN T16/T19, §5 applicable gesture/scroll/zoom/rotation steps; accepted T012 build and physical devices.

## Acceptance criteria

Record device/OS/browser and 10 legal plus 10 invalid/cancelled gestures per platform, long-column scrolling, pinch, rotation and background/foreground. Zero card/state corruption, duplicate moves, accidental drag scrolling or stranded targets. P6 exit met. Offline/install/update steps are explicitly deferred to P9.

Acceptance reference: P6 exit; TEST_PLAN T16/T19 and §5 (pre-PWA subset).

## Required tests

Run physical script on Android Chrome and iOS Safari; npm run test:e2e -- tests/e2e/input.spec.js tests/e2e/layout.spec.js after fixes; applicable unit tests. Missing device evidence cannot be marked passed.

Run only commands supported by this task's resulting repository. Report exact commands/results and any unrun checks; do not weaken acceptance because a tool/device is unavailable.

Follow [report requirements](../reports/README.md). Commit only task-owned changes with prefix `T013:`, set REVIEW only when required work/checks are ready, and stop. Only explicit coordinator acceptance makes DONE. For interruption/blockers, checkpoint progress with precise resume instructions. Do not start a successor.
