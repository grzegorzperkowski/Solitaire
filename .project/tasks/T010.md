- Milestone: P5
- Dependencies: T009

## Acceptance criteria

Tap and keyboard can perform legal transfers/stock/history actions exactly once; selection/rejection precedence matches F01. Focus survives moves/Undo, Tab leaves board, zoom is preserved, hidden sources are inaccessible. Keyboard shortcuts ignore text fields. No DOM-derived game rules.

Acceptance reference: P5 input subset; TEST_PLAN T15/T18 (board).
