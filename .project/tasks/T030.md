# T030 — Prevent double-click zoom on buttons and cards

- Milestone: P5 follow-up
- Dependencies: T010 DONE
- Assigned: 2026-10-21 by the human coordinator
- Implementer: Codex
- Status: see [TASKS.md](../TASKS.md)

## Scope

Prevent browser double-tap zoom on native buttons and face-up cards, including cards with `role="button"`. Preserve pinch zoom, card drag, tableau scrolling, keyboard and single/double-tap game actions. Reuse CSS touch-action rules; do not disable browser zoom globally.

## Acceptance criteria

- Native buttons and face-up cards compute to `touch-action: manipulation` on mobile emulation, including buttons rendered after opening a dialog.
- Face-up card drag and pinch zoom acceptance behavior remains supported.
