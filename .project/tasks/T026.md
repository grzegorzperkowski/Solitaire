## Scope

Make the production Solitaire build consumable by the Playground app assembler and available at `/mygame/apps/solitaire/` with the same shared PWA behavior as the other nested games. Keep the standalone `/Solitaire/` deployment working. The Playground manifest, service worker, install/update flow and offline shell remain shared; do not add a competing nested manifest or service worker. Preserve Solitaire saves and game behavior.

Coordinate changes in both `C:\Sources\MyProjets\Solitaire` and `C:\Sources\MyProjets\mygame`. Do not push or publish either repository.

## Expected files or modules

Solitaire build/deployment configuration and any source metadata required for the nested build; `mygame/scripts/sync-apps.ps1`, `.github/workflows/pages.yml`, `manifest.webmanifest`, and generated app-shell inputs as needed; focused build/integration checks; this task report and project task tracking.

## Acceptance criteria

- CI assembles the Solitaire production output from the Solitaire repository into `mygame/apps/solitaire/`, with all runtime assets resolving beneath both `/Solitaire/` and `/mygame/apps/solitaire/`.
- The launcher card and manifest shortcut open the nested game. Its page uses the shared Playground manifest and registration path, has the standard Playground breadcrumb, and does not register a second service worker or claim its own install prompt.
- The Playground shell includes every Solitaire runtime asset and has an offline navigation fallback for `/mygame/apps/solitaire/`; after shell readiness, the game loads offline and a saved session survives reload.
- Solitaire remains independently buildable and usable at its standalone deployment path. Existing local save data is not reset or migrated destructively.
- The mygame sync/check workflow and Solitaire production build validate the generated nested tree. No deployment or push is performed.

## Required checks

Exercise the built app at the repository subpath and nested Playground path, including offline reload after readiness and save restore.
