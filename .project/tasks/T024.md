# T024 — Double-tap card shortcut

- Milestone: P5 follow-up
- Dependencies: T010 DONE
- Assigned: 2026-10-10 by the human coordinator (“implement the double-tap task; create a new task as needed”)
- Implementer: Codex

## Scope

On touch, detect a second tap within 350 ms on the same movable face-up card. If the board has not changed, execute its first currently legal destination in the existing order (tableau columns, then foundations) through the existing validated move path. Repeating after a move recomputes the card's current source and legal destinations. Preserve single-tap selection/deselection, touch scrolling, pinch zoom, drag behavior, mouse and keyboard behavior.

## Acceptance criteria

- A quick second touch tap on the same movable face-up card executes exactly one move to the first current legal destination.
- Repeating the gesture uses the new board and current source; an unavailable destination makes no move.
- Single tap, different-card tap, drag, cancellation, mouse double-click, keyboard and unrelated controls retain their existing behavior.
- Move uses the existing validated command path, announcements and focus handling.

## Required tests

`npm run test:e2e -- tests/e2e/play.spec.js`; `npm test`. Cover deterministic destination order, exactly-once move, repeated gesture from updated state and touch cancellation/drag preservation.
