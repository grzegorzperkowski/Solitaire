# T022 — Full release verification and handoff

- Milestone: P10
- Dependencies: T021; T016 also DONE only if selected for release
- Model suitability (advisory, not assignment): Any model with full test tools and human/device access.
- Status: see [TASKS.md](../TASKS.md); only the coordinator assigns this task.

## Scope

Run clean full release checks, required devices and requirement-to-evidence mapping. Fix only release-blocking defects found in this scope with regression tests. Record artifact/commit and operational limitations; do not publish.

## Required inputs

Read [AGENTS.md](../../AGENTS.md), [STATUS.md](../STATUS.md), [HANDOFF.md](../HANDOFF.md) and any existing task report first. Then read: TEST_PLAN entire release gate; all mandatory accepted task reports; optional-feature decision; ARCHITECTURE/REQUIREMENTS release budgets.

Sources: [requirements](../../REQUIREMENTS.md), [architecture](../../ARCHITECTURE.md), [milestones](../../IMPLEMENTATION_PLAN.md), [test plan](../../TEST_PLAN.md). Two-digit T01–T23 identify test groups; three-digit T000–T023 identify work tasks.

## Expected files or modules

docs/release-check.md, README.md, tests/unit/simulation.test.js, tests/e2e/; source/config only for demonstrated release-blocking fixes.

Every task also updates its report, TASKS, STATUS and HANDOFF as needed; file lists are intended scope, not permission for unrelated edits.

## Acceptance criteria

All mandatory test groups and required physical browsers have evidence; coverage/asset/performance targets pass; release simulation runs 10,000 seeds/mode up to 1,000 steps. No unresolved blocking defects/unexplained skips. T21 test group required only if optional T016 shipped. Deliver verified artifact/commit; P10 publication evidence remains T023.

Acceptance reference: P10 verification subset; TEST_PLAN T01–T23 (T21 conditional), §§4–7.

## Required tests

npm ci; npm test; npm run test:coverage; npm run test:simulation -- --profile=release; npm run build; npm run test:e2e. Complete TEST_PLAN §§5–7 manual/device checks and record exact versions/results.

Run only commands supported by this task's resulting repository. Report exact commands/results and any unrun checks; do not weaken acceptance because a tool/device is unavailable.

## Delivery and stop

Follow [report requirements](../reports/README.md). Commit only task-owned changes with prefix `T022:`, set REVIEW only when required work/checks are ready, and stop. Only explicit coordinator acceptance makes DONE. For interruption/blockers, checkpoint progress with precise resume instructions. Do not start a successor.
